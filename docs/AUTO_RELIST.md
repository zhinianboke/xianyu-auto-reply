# 商品自动续售

自动续售用于普通闲鱼商品成交后库存归零、商品自动下架的场景。

## 配置步骤

1. 在“商品素材库”准备与当前商品一致的素材。
2. 在“卡券管理”准备并启用自动发货卡券。
3. 在“商品管理”获取一次对应闲鱼账号的商品。
4. 回到“商品素材库”，点击素材行末尾的循环箭头。
5. 选择闲鱼账号、当前在售商品、自动发货卡券和等待时间，保存并启用。

## 执行条件

系统每 30 秒检查一次，只在以下条件全部满足时重新发布：

- 规则处于启用状态；
- 当前商品产生了新订单；
- 订单已由系统自动发货并保存发货内容；
- 等待时间已结束；
- 闲鱼实时在售列表中已经找不到旧商品。

发布成功后，系统会保存新商品 ID，把原卡券关联到新商品，并继续监听新商品。发布失败最多自动重试 3 次；配置页可以查看错误和最近执行记录，重新保存配置可恢复失败任务。

## 停止方式

在素材的“自动续售”弹窗关闭开关并保存。关闭项目的一键脚本也会停止调度器，期间不会执行自动续售。

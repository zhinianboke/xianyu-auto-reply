# 闲鱼发货管理后台

一个纯前端的闲鱼发货管理工具，支持商品管理、二维码生成、发货记录。买家扫码后可在浏览器中查看网盘链接和提取码。

## 功能特性

- 📦 **商品管理**：添加/编辑/删除商品，配置网盘链接和提取码
- 📱 **二维码生成**：为每个商品生成二维码，支持下载 PNG
- 📋 **发货记录**：记录已发货订单，便于管理
- 💾 **本地存储**：数据保存在浏览器 localStorage，支持导出/导入备份
- 🎁 **买家发货页**：买家扫码后展示网盘链接和提取码，支持一键复制

## 文件说明

| 文件 | 用途 |
|------|------|
| `index.html` | 管理后台（商品管理、二维码生成、发货记录） |
| `delivery.html` | 买家发货展示页（扫码后打开） |

## 使用方法

### 1. 部署

将 `index.html` 和 `delivery.html` 放到同一目录下，通过 Web 服务器访问（如 GitHub Pages、Nginx、本地 `python -m http.server`）。

**推荐部署到 GitHub Pages：**
1. 仓库已上传到 `xianyu-auto-reply/delivery-admin/`
2. 在 GitHub 仓库设置中开启 GitHub Pages，选择 main 分支
3. 访问地址类似：`https://18488292860-coder.github.io/xianyu-auto-reply/delivery-admin/`

### 2. 配置基础地址

1. 打开管理后台 `index.html`
2. 进入「系统设置」
3. 填写发货页面基础地址，例如：
   ```
   https://18488292860-coder.github.io/xianyu-auto-reply/delivery-admin/
   ```
4. 点击保存

### 3. 添加商品

1. 进入「商品管理」
2. 点击「添加商品」
3. 填写商品名称、网盘链接、提取码等信息
4. 保存后自动生成二维码

### 4. 发货流程

1. 在商品卡片上点击「📱 二维码」
2. 下载二维码图片
3. 把二维码图片发给买家
4. **买家操作**：闲鱼扫描二维码 → 闲鱼显示安全提示 → 点击「在浏览器中打开」→ 查看网盘链接和提取码

### 5. 记录发货

1. 进入「发货记录」
2. 点击「记录发货」
3. 选择关联商品、填写订单号
4. 保存记录

## 关于闲鱼扫码

闲鱼扫描外部链接二维码的安全机制：

1. 闲鱼显示**安全提示页**（告知用户这是外部链接）
2. 用户需**手动点击「在浏览器中打开」**
3. 跳转到系统浏览器打开发货页面

这是闲鱼的正常安全风控机制，无法绕过。建议在给买家发送二维码时，附上文字说明"请用浏览器打开"。

## 数据备份

- 在「系统设置」中可导出全部数据为 JSON 文件
- 也可导入之前的备份数据
- 数据保存在浏览器 localStorage，清除浏览器数据会丢失，请定期备份

## 技术栈

- 纯 HTML + CSS + JavaScript
- [qrcodejs](https://github.com/davidshimjs/qrcodejs) 二维码生成库
- localStorage 本地存储

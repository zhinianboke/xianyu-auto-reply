# 闲鱼卖家库存与发货时效

在当前已登录的闲鱼卖家后台内，安全地批量更新符合条件的商品。默认不使用未验证的内部接口，且不绕过登录、验证码、人脸认证或平台风控。每次操作都必须先完成范围、可修改配置和预期配置的确认，再执行任何写入。

## 工作前提

- 在本次确认单之后，取得用户对范围和预期配置的明确确认；确认前不得进行写入。
- 使用当前已登录的卖家会话；如遇登录、二维码、验证码或人脸验证，展示给用户并等待其本人完成。
- 使用浏览器操作卖家后台。不要猜测或调用未验证的 MTop、私有编辑或发布接口。
- 按商品顺序处理。不要并行发布，避免页面状态、风控或发布结果相互干扰。

## 执行流程

### 1. 确认范围、可修改配置与预期配置（只读）

1. 打开商品管理页：`#/seller-item/goods-manage`。
2. 返回第一页，逐页读取商品 ID、原价、库存、“编辑”与“设置粉丝价”入口；直到下一页不可用，并按商品 ID 去重。
3. 确定范围：列出商品总数、满足筛选条件的商品 ID 数量、排除条件和例外商品。范围不明确时，停止并向用户询问，不要自行扩大范围。
4. 确认可修改配置：逐项列出当前账号和每类商品实际可见、可编辑的字段，例如库存、24/48 小时发货、全部粉丝价和无需邮寄；同时列出无“编辑”入口、无“设置粉丝价”入口或仅 App 可发布等限制。
5. 确定预期配置：为每个本次请求的字段写明条件、当前值范围和目标值。粉丝折扣须写明计算规则和取整方式；库存、发货承诺和发货方式须写明启用、关闭或保留状态。
6. 向用户展示确认单，至少包含“范围”“可修改配置”“预期配置”“例外/不可修改项”和预计发布数量，并请求明确确认。
7. 在用户发送本次确认单对应的“确认”或等效授权前，**只能读取和汇总**；不得填入数值、切换开关或单选项、点击“确定”或“发布”。

确认单格式：

| 项目 | 内容 |
| --- | --- |
| 范围 | 筛选条件、商品数量与商品 ID 范围 |
| 可修改配置 | 已验证存在且可编辑的字段 |
| 预期配置 | 每个字段的目标值、条件与计算规则 |
| 例外 | 无入口、仅 App 发布或字段缺失的商品 ID 与原因 |

### 2. 设置粉丝价

仅当用户要求粉丝价时执行：

1. 在商品管理列表点击该商品的“设置粉丝价”，打开“编辑粉丝价”窗口。
2. 读取窗口内的原价，并只编辑“全部粉丝：粉丝价”列；除非用户明确要求，不要填写“老粉”或“已购粉”列。
3. 将折扣转换为金额。98 折应为原价 × 0.98，并按人民币分位四舍五入到两位小数。
4. 回读输入值后点击“确定”，等待明确的“编辑成功”结果；若通知不可见，重新打开该商品的设置窗口并回读价格后再记录成功，不能仅凭窗口关闭判定。
5. 如果分页末行入口被悬浮客服遮挡，基于刚读取的商品 ID 重新定位该入口后再点击；不要复用上一行的索引或坐标。
6. 没有“设置粉丝价”入口的商品标记为“无粉丝价入口”，不要猜测接口或伪造成功结果。

### 3. 编辑并发布每件商品

对每个待处理商品执行以下操作：

1. 进入编辑页，等待本次任务所需字段和“发布”均已加载。涉及“无需邮寄”时，必须同时确认“发货设置”和该选项存在。
2. 在当前 DOM 中确认本次需要修改的输入框、开关或单选项唯一；定位不唯一、字段缺失或页面加载失败时停止该商品并记录原因。
3. 仅在用户要求时，将“48小时发货”切换为关闭、将“24小时发货”切换为开启，或将库存补至目标值。
4. 用户要求“无需邮寄”时，选择该发货方式，等待表单状态稳定，并回读该单选项已选中。
5. 再次读取所有本次目标字段，确认值与用户要求一致。
6. 确认“发布”按钮唯一且可用后点击一次，等待明确的“发布成功”结果。
7. 未出现成功提示时，先检查页面提示、表单状态和网络等待结果；不要因超时直接重复点击发布。

## 异常处理

- 出现“该商品暂不支持网页发布，请到闲鱼 APP 发布”时，停止该商品的网页操作，记录商品 ID、未能保存的字段和当前值，标记为“需 App 发布”。不要重试网页发布或改用未验证接口。
- 出现表单校验错误、字段变更或发布失败时，记录商品 ID、页面提示和已确认的字段状态；不要把表单中的未发布值当作已保存。
- 出现风控、验证码、二维码或人脸认证时，暂停并请求用户本人完成验证；不要尝试绕过。

## 最终复核

1. 回到商品管理页并重新逐页扫描全部分页。
2. 输出扫描页数、粉丝价成功数量、已成功发布数量，以及所有未达目标商品的 ID、字段和原因。
3. 仅当复核未发现本次目标字段的异常时，报告“全部完成”；若有无粉丝价入口、App 限制或其他异常，明确报告剩余范围。
4. 保留商品管理页，方便用户复查。
